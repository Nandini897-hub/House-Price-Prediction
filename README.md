 House Price Prediction Using Machine Learning

 About the Project
This project focuses on predicting house prices using Machine Learning techniques. It analyzes various housing features such as living area, number of bedrooms, bathrooms, floors, and other factors to estimate house prices.

Objectives
- Analyze housing data to understand price patterns.
- Perform data cleaning and preprocessing.
- Explore relationships between different housing features.
- Build and evaluate Machine Learning regression models.
- Predict house prices using the best-performing model.

 Machine Learning Models
The following regression algorithms were implemented:
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

The models were evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

Random Forest Regressor achieved the highest R² score among the implemented models.
